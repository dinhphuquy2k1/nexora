# Inter

Inter 4.1, normal variable WOFF2 (weights 100–900), from upstream release tag:
https://github.com/rsms/inter/tree/v4.1/docs/font-files

Original file: `InterVariable.woff2` (unmodified).
License: SIL Open Font License 1.1; upstream `LICENSE.txt` retained as `OFL.txt`.
Includes Latin and Vietnamese glyphs. Root layout uses next/font/local; there is
no external font request at runtime or build. No font package dependency added.
