Update ADR011 with this dated decision without rewriting old rule/history.

## 7. Typed attributes boundary

Add provider_attributes JSONB NULL. Stored schema is {schemaVersion:1,provider:<trusted provider>,values:{originWarehouseId?,freightUnitPrice?:{amount,currency,unit:kg},providerCreatedAt?,lastMileMethod?}}. Generic Shipment Domain validates these neutral reference concepts; only Uniship infrastructure maps ChinaStoreID/PriceAmount/etc. No Uniship wire dictionary in Domain. Provider string must match trusted create scope or hydrated root; unknown keys/version/namespace invalid. Limit1024 UTF8 bytes, closed object depth3; no recursion/unknown containers, no JSONB index. Parse/hydrate validate stored values. Unknown stored schema is rejected, never silently stripped.

Input providerAttributesPatch uses the same version/namespace and bounded selected values. Omission/null leaf means preserve; no deletion operation. Nested freight price is validated as a whole object, merged at the four known field slots, never recursive generic merge. Scalars and canonical fields cannot appear in attributes. Resolve under root lock and emit providerAttributes only when a nonempty patch exists. No unvalidated JSON writer exposed. Persistence binds JSONB using explicit cast; worker column grant cannot enforce keys, so Domain/adapter tests prove restrictions. Physical CHECK enforces object/version/provider/size baseline; no claimed complete DB key-level policy.
