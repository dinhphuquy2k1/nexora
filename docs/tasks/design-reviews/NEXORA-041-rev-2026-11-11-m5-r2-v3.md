## 6. Alternatives

Reject feature logic in UI, a new pagination algorithm, generic count inference,
new UI libraries, copied dismiss hook and business-aware shared filters. Preserve
feature state and CSS exceptions rather than flattening differences into a new
visual design. Page-size selection remains actual Select markup in the slot;
feature callbacks continue owning reset policy.

## 7. Interfaces and DDD alignment

PagerProps: page:number; pages:readonly number[]; targets:{first,previous,next,last}
(all numbers); disabled:{first,previous,numbers,next,last} (all booleans);
onPage(number); summary:ReactNode; pageSize?:ReactNode; summaryClassName?:string;
selectedVariant:ButtonVariant; icons:{first,previous,next,last} (ReactNodes);
labels:{navigation,first,previous,next,last,page(number)}; currentPageKnown?:boolean;
numberIcon?:boolean; pressEffect?:ButtonProps['pressEffect']; numberLayout?:
'grouped'|'inline'; navigation/selected/unselected class hooks. No total calculation,
fetch/URL logic, app imports, icon dependency, or automatic enabled state.

FilterPopoverShellProps: trigger:ReactNode, triggerLabel/dialogLabel/title,
children({close}):ReactNode; onDismiss?; triggerPressEffect?;
anchor/panel/headingClassName?; initialFocusSelector? (default select).
Shell holds open state/refs/useId; trigger gets id/aria-controls/expanded/haspopup;
panel id and existing dialog label. Explicit close restores trigger focus;
outside does not; Escape delegates to canonical hook. onDismiss runs on actual
dismiss/explicit close, not trigger toggle, retaining Carrier error semantics.
Low-specificity CSS owns common anchor/surface/header/form structure; feature CSS
retains only specific width/offset/border/spacing/typography/mobile differences.

Presentation-only extraction needs no Aggregate/Entity/VO: reviewed omission under
ADR008. No persistence, port, command, query, lock or ownership changes.
