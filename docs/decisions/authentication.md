# ADR-005 · Defer authentication

Accepted: foundation is local-only with loopback web port; login/session/RBAC is PLANNED. Do not claim protection or expose it to the Internet. Public hosting, multiuser access, TLS and AI key encryption/key management need a separate milestone and threat model.
AI has no live provider adapter in foundation. Keys will remain server-side; no key is required for readiness. Notes cannot become authoritative monetary decisions. Do not copy SEIZA auth fixtures into any release image.
