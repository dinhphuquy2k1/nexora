# Frontend

Next.js App Router is UI plus transport-only `/api/:path*` rewrite. Runtime/server config selects `http://api:4000`; browser uses generated SDK with relative same-origin URLs. No database, secret or API_INTERNAL_URL is in client imports. Build consumes committed SDK; it never generates contracts.
Pages: overview labels unimplemented workflow, `/system` makes real health requests on mount/refresh, `/settings` shows version/local mode and explicitly marks future settings unimplemented. Network failure shows an actionable message. UI has Vietnamese labels, responsive layout, focus states and no simulated results.
Next uses ordinary `next build --webpack` + `next start`, not standalone. Workspace UI/SDK sources are transpiled by Next. Shared dist is built first and watched in development.

Next owns `next-env.d.ts` and `.next` generated type outputs; they are ignored and regenerated by dev/build. OpenAPI SDK outputs remain committed and are checked separately for drift.
