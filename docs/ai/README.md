# AI Contributor Entry Point

This is the mandatory starting entry point for AI-assisted work in Nexora. Follow this sequential reading order; do not read the entire repository tree by default.

## Required reading order

1. [Project context](PROJECT_CONTEXT.md): System mission, technology stack, and architectural invariants.
2. [Project rules](PROJECT_RULES.md): Non-negotiable engineering priorities, boundaries, and domain rules.
3. [Task workflow](TASK_WORKFLOW.md): Task lifecycle, status vocabulary, evidence schema, and Documentation Impact.
4. [Implementation workflow](IMPLEMENTATION_WORKFLOW.md): Mandatory step-by-step procedure: classify, plan, TDD, verify, report.
5. [Document router](DOCUMENT_ROUTER.md): Task-oriented reading route guidance.
6. Relevant architecture documents under [`../architecture/`](../architecture/).
7. Relevant domain documents under [`../domains/`](../domains/).
8. Relevant accepted ADRs under [`../decisions/`](../decisions/).
9. The active task record under [`../tasks/active/`](../tasks/active/), when one exists.

The [Implementation workflow](IMPLEMENTATION_WORKFLOW.md) is a mandatory rule for every implementation task.
